# 游戏 Demo

一个用于练手和探索 Unity 功能的游戏 Demo，主要用来看看自己目前的技术水平能实现哪些效果。

## 项目简介

- 这是一个 Unity 游戏 Demo。
- 主要使用 **C#** 语言开发。
- 目前已适配 **Android** 和 **PC** 平台。
- 项目没有复杂依赖，直接在 Unity 中 Build 即可运行。

## 技术栈

- Unity
- C#

## 已适配平台

- [x] PC
- [x] Android

## 构建方式

1. 用 Unity 打开项目。
2. 打开 `File -> Build Settings`。
3. 选择目标平台（PC 或 Android）。
4. 点击 `Build` 即可。

没有额外的依赖安装步骤。

## 依赖
